# Algoritmos 141 a 150 em Kotlin

Este repositório contém os algoritmos de 141 a 150, originalmente escritos em Portugol e convertidos para Kotlin.

O objetivo da atividade é praticar a linguagem Kotlin e aprofundar o uso de estruturas condicionais avançadas, expressões `when`, ordenação de coleções (`sortedByDescending`), manipulação de strings e caracteres, além de aplicações práticas de lógica de negócios, matemática, trigonometria, finanças e regras institucionais.

**Algoritmos desenvolvidos**

- Algoritmo 141: Lê o nome e pontuação de três finalistas de pingue-pongue e exibe a colocação em formato de pódio.
- Algoritmo 142: Processa os pontos de uma equipe de arco-e-flecha, exibe os valores em ordem decrescente e calcula a média aritmética se a soma for maior que 100.
- Algoritmo 143: Analisa a(s) letra(s) central(is) de uma palavra (verifica se é vogal se o comprimento for ímpar, ou se forma os dígrafos "rr" / "ss" se for par).
- Algoritmo 144: Calcula o crédito especial de um cliente com base em faixas de saldo médio no último ano.
- Algoritmo 145: Emite um recibo de empréstimo de biblioteca definindo prazos específicos de devolução para professores e alunos.
- Algoritmo 146: Calcula o consumo estimado de combustível com base no percurso em quilômetros e no tipo de veículo (A, B ou C).
- Algoritmo 147: Soma as calorias totais de uma refeição a partir das escolhas de prato, sobremesa e bebida.
- Algoritmo 148: Informa o preço da passagem de acordo com a região de destino e o tipo de viagem (ida ou ida e volta).
- Algoritmo 149: Calcula o preço de venda de um produto aplicando margens de lucro progressivas com base no valor de compra.
- Algoritmo 150: Calcula o seno (se o quadrante for par) ou o cosseno (se o quadrante for ímpar) de um ângulo fornecido em graus.

**Comentários sobre os exercícios**

Neste bloco, consegui consolidar o uso de estruturas condicionais avançadas, ordenação de listas, mapeamento com a expressão `when` do Kotlin aplicadas a problemas práticos, como classificação de pódios, cruzamento de tabelas de preços e calorias, e funções trigonométricas da biblioteca padrão (`Math.sin`, `Math.cos`).

Também explorei recursos idiomáticos do Kotlin, como tratamento seguro de nulos (`?.`, `?:`), formatação de decimais (`%.2f`), manipulação de strings (`lowercase()`, `uppercase()`, `trim()`), garantindo um código limpo, seguro e legível.

Os arquivos estão organizados individualmente, de Algoritmo141.kt até Algoritmo150.kt, dentro da pasta `src/main/kotlin`.

Cada arquivo contém o enunciado, o código original em Portugol e sua conversão para Kotlin.
